# Big Data Analytics Projects
A comprehensive portfolio showcasing hands-on projects in big data analytics, demonstrating proficiency in Python, SQL, PySpark, Databricks, and Microsoft Fabric. This repository consolidates key projects and coursework to highlight practical skills in data processing, machine learning, and business intelligence.


## 📁 Repository Structure
- `Big_Data_Analytics_Specialization/:` Projects from the Big Data Analytics Specialization at Arcada University of Applied Sciences. This includes coursework covering a wide range of topics, from fundamental analytics to machine learning and visual analytics.

- `Databricks_Airbnb_Data_Analysis/:` An end-to-end data analysis project using Databricks SQL to analyze Airbnb listings. The project demonstrates advanced data cleaning, feature engineering, and business intelligence techniques.

- `PySpark_Customer_Segmentation/:` Customer segmentation using KMeans clustering on an e-commerce retail dataset, built with PySpark MLlib on a local Spark session.

- `Microsoft_Fabric_NycTaxi_Data_Analysis/:` End-to-end medallion architecture (Bronze/Silver/Gold) for NYC Yellow Taxi 2024 data, built entirely in Microsoft Fabric (Lakehouse, Warehouse, Pipelines, Power BI). **Requires a Microsoft Fabric workspace.**

- `Microsoft_Fabric_Brazilian_E_Commerce_Olist/:` Bronze → Silver lakehouse pipeline for the Brazilian Olist e-commerce dataset in Microsoft Fabric. **Requires a Microsoft Fabric workspace.**

- `Microsoft_Fabric_RTI_Crypto_Prices/:` Real-time crypto price streaming from Binance US → Azure Service Bus → Fabric Eventstream. **Requires a Microsoft Fabric workspace and a Service Bus connection string (set `CONNECTION_STR` from Key Vault or an environment variable — never hardcode credentials).**


## 🛠️ Technical Skills
The projects in this repository highlight expertise in the following areas:

**Languages:** SQL, Python (PySpark, pandas), KQL, DAX

**Platforms & Tools:** Microsoft Fabric, Databricks, Azure Service Bus, Power BI, Git

**Concepts:** Data Cleaning, ETL, Medallion Architecture, Real-Time Streaming, Feature Engineering, Machine Learning, Visual Analytics, Business Intelligence
